Why Direct

전용기도, 범용 로봇도 아니다.

전용기는 라인이 바뀌면 발이 묶이고, 범용 로봇은 통합이 막막합니다. mcc_desk는 그 사이에서, 당신의 공정에 맞게 직접 통합하는 길을 엽니다.

현장의 고민

지금 이런 벽에

  • 전용기 — 한번 세팅하면 라인 전환이 어렵다
  • 수작업 — 작업자마다 품질 편차가 생긴다
  • 범용 로봇 — 실험 중 파손·설정 변경이 번거롭다
  • 블랙박스 — 내부 시스템과 연동이 막힌다
mcc_desk의 답

이렇게 풉니다

  • 개방형 API로 MES·PLC·자체 SW 직접 연동
  • 비전 위치 보정으로 안정적 자동 작업
  • 직관적 작업 편집 — 현장도 엔지니어도
  • 3축에서 시작해 모듈로 확장·재사용

Capabilities

직접 통합에 필요한 것은 이미 열려 있다.

⇄

개방형 API

MES·PLC·자체 소프트웨어와 직접 연동. Python 포함 제어 인터페이스로 공정 데이터를 바로 뽑습니다.

◎

비전 위치 보정

부품이 트레이에 정확히 놓이지 않아도 위치·각도를 찾아 모션 명령으로 즉시 변환합니다.

▣

외관 검사·계측

표면 결함·이물·누락 검출과 에지·원·코너 치수 계측을 한 플랫폼에서.

✎

작업 편집

현장 작업자도 간단한 경로 수정은 직접. 엔지니어는 파라미터를 바로 조회·조정합니다.

⊕

모듈형 확장

3축으로 시작해 로터리 테이블·툴 모듈을 더합니다. 공정이 바뀌면 플랫폼을 재사용합니다.

◱

진단 데이터

공정 이력·품질 리포트·예지보전 데이터를 수집해 내부 시스템으로 보냅니다.

Product Lineup

🧩

mcc_desk 3축 모듈

제어 컨트롤러 + 개방형 API 내장. 소형 정밀 작업의 핵심 본체로, 자체 SW와 바로 연동합니다.

🔁

2축 로터리 테이블

작업물 자세를 바꿔 접근 방향을 확보. 3축에 더해 최대 5축 구성으로 공정을 넓힙니다.

🛠️

툴 모듈

디스펜서·드라이버·마킹 등 공정별 엔드이펙터를 표준 인터페이스로 교체합니다.

✎

작업 편집 SW

No-code/Low-code로 작업 경로를 구성. 현장 작업자도 수정하고 엔지니어는 파라미터를 바로 조정합니다.

◎

비전 솔루션 SW

위치 보정·패턴 매칭·외관 검사·치수 계측을 하나의 씬에서 모션과 묶습니다.

📊

진단 데이터 수집 SW

공정 이력·품질 리포트·예지보전 데이터를 수집해 MES·내부 시스템으로 전달합니다.
